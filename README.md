# Verificar orden de lista

## Descripción

Este proyecto esta desarrollado en Python y verifica si una lista de cualquier tipo ya sea string, int, float, etc. Esta ordenada o no de forma ascendente.

## Características

- Ayuda a verificar si una lista está ordenada o no.
- Muestra el resultado al usuario.
- Esta construido con una estructura básica de Python, usando bucles y condicionales.

## Tecnología/s

Python 3

## Ejecución del programa

1. Descarga el proyecto.
2. Abre una terminal de Git Bash en la carpeta del proyecto.
3. Ejecutar:

~~~bash
Python verificar_orden_lista.py
~~~
